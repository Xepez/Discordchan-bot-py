# Discordchan-bot-py
Basic discord bot for my personal server


## How to use:
- Download project
- Create a config.json file
- You will then need to define a few fields in the config.json
  - [Discord Token](https://discordpy.readthedocs.io/en/latest/discord.html)
  - [Safebooru Login](https://safebooru.org/index.php?page=help&topic=dapi)
- Run
  - Windows: py -3 discordchan_bot.py
  - Other: python3 discordchan_bot.py


## Commands:
- ping: Bot will respond pong
- cat: Bot will respond with a random picture of a cat
- randome: Bot will respond with a random picture from Safebooru
